# Si shtohen fjalë të reja

Fjalët fillestare janë te `js/words-1.js` deri te `js/words-4.js`. Çdo rresht ka 4 pjesë të ndara me `|`:

```
fjala|lloji|kuptimi|shembulli në fjali
```

Shembull:

```
mall|emër|Dëshirë e fortë për dikë a diçka që të mungon.|Kam mall për shtëpinë.
```

Fjalët mund t’i shtosh edhe direkt në aplikacion, te skeda "Fjalori". Ato ruhen në shfletues.
